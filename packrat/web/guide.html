Guide

How to browse your library, sync itch.io purchases, and use Packrat from Claude. Commands follow the Windows / Linux switch.

Everyday use

Library

  • Library browses packs by folder, type and tag. Search (press /) finds packs and individual files, including files inside zip and rar archives.
  • On a pack page, Copy path copies where the pack lives on disk. The Your notes panel stores vendor, license, tags, rating and favorite.
  • Rescan (top right) re-indexes your library folders after you add or move packs.

Adding new assets

  • Put each pack in its own folder (or leave it as a single zip/rar) directly inside one of your library folders, then press Rescan.
  • Folders that only contain archives (like Music) are treated as bundles automatically, so each archive inside becomes its own pack.
  • If you keep the original zips next to extracted copies, store them outside your library folders so they don't show up as duplicates.

itch.io purchases

  • Purchases lists everything you own on itch.io and whether it's in your library. Files are matched by exact name and size, then by size only, then by pack name.
  • Sync itch.io imports new purchases. Packrat can also sync on a schedule while it runs.
  • Download (per purchase) or Download all missing saves files to your download folder, one folder per purchase. Each download is checked against itch.io's checksum before it's kept.
  • Extras such as GameMaker .yymps packages, .exe files, HTML demos and License.txt are listed but don't count as "missing".
  • Hide removes purchases you'll never want from the lists. Type in the filter box to get a Hide all shown button for bulk hiding.

Connect Claude

Packrat includes an MCP server that gives Claude Code tools to search your library, view previews, read license files, and copy assets into the project you're working in. Register it once per computer; it applies to all your projects. Packrat must be running.

In PowerShell:

irm http://localhost:8765/install.ps1 | iex

In a terminal:

curl -fsSL http://localhost:8765/install.sh | sh

Then restart Claude Code and type /mcp. You should see packrat ✔ connected. To remove it: claude mcp remove packrat -s user.

Using it from Claude

Say "my Packrat library" in the request so Claude reaches for the Packrat tools. Claude searches, looks at contact sheets before choosing, checks licenses, and copies files into the project. It never changes the library itself.

Explore what you have

What kinds of assets are in my Packrat library? Summarize by category and show me a few highlights.

Find art that fits a project

Look at the art already in ./assets, work out its tile size and style, then find tilesets in my Packrat library that would match it. Show me previews before copying anything.

Specific files

Find a treasure chest with an opening animation in my Packrat library, work out the frame size from the sprite sheet, and copy it to ./assets/sprites.

Sound, music and fonts

Find short UI click, hover and confirm sounds in my Packrat library that sound like they belong together, and copy them to ./audio/ui.

Licenses and credits

For every asset you copied from my Packrat library in this session, check the pack's license or usage terms and write a CREDITS.md listing each pack, author, link and whether attribution is required.

Make it a habit in a project

Add a line like this to the project's CLAUDE.md:

Game art, sound, music and fonts come from my Packrat library (packrat MCP tools).
Preview before choosing, keep the style consistent with ./assets, copy into ./assets,
and record the license terms of anything used in CREDITS.md.

Troubleshooting

Claude doesn't use Packrat, or /mcp shows packrat as failed
Check that this page opens in a browser on that computer. If it does, run the command from Connect Claude again, then restart Claude Code. Say "my Packrat library" in requests.
itch.io sync fails or says the API key is missing
Create an API key on itch.io under Settings → API keys and add it to Packrat. If the key was revoked, create a new one.
.rar or .7z packs show no files
Packrat needs 7-Zip to read them. On Windows install 7-Zip from 7-zip.org; on Linux install 7zip (or p7zip-full) from your package manager. Then press Rescan.
A purchase says "page no longer available"
The creator unlisted or removed its itch.io page. Its files still download; only the tags and terms are missing.

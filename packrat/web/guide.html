Guide

Browse your asset library, keep your itch.io and Humble purchases downloaded, and use it all from Claude.

Getting started

  • In Settings, add the folders where you keep asset packs. Packrat only reads them; it never changes, moves or deletes your files.
  • Each folder or zip/rar directly inside a library folder is one pack. A folder holding only archives (like Music) counts each archive as its own pack, except a purchase's folder in your download folder, which stays one pack.
  • After adding or moving packs on disk, press Rescan (top right).
  • A folder holding pack folders, like a bundle, would count as one big pack: mark it with Folder of packs… in Settings.
  • If you keep backups or original zips next to extracted copies, use Ignore a folder… in Settings so they don't show up twice.

Everyday use

  • Library browses packs by folder, type and tag. Recently added shows what's new this week.
  • Search (press /) finds packs and files, including files inside zip and rar archives. The itch.io tab searches itch.io instead.
  • A pack page previews its files. Copy path copies where a file is; Show in folder opens it in your file manager. Your notes holds your own notes, tags, license, rating and favorite.
  • Scans, syncs and downloads show their progress at the top of every page.

Free assets

  • Search, open the itch.io tab, then press Add & download. When it's done, Open pack takes you to it.
  • Or paste an itch.io page link into the search box.
  • Free only and Refine narrow the results. itch.io search stops at about 50 results; More continues with free assets that have your search word as a tag.
  • Paid assets open on itch.io. After you buy one, press Sync on the Purchases page.

itch.io purchases

  • Connect your account in Settings with an itch.io API key. Packrat then syncs your purchases, by default once a day (Settings → Syncing).
  • Purchases shows what you own and whether it's already in your library. Files are matched by name and size, so packs you already have aren't downloaded again.
  • Download (one purchase) or Download all missing saves to your download folder, one folder per purchase. Each file is checked against itch.io's checksum. Cancel at the top stops downloads; finished files are kept.
  • Extras (GameMaker packages, installers, HTML demos, license files) are listed but don't count as missing.
  • Hide takes purchases you don't want off the lists. Type in the filter box to hide many at once.

Humble Bundle (experimental)

  • Humble has no public API, so Packrat signs in with your browser's Humble session cookie. It may stop working when Humble changes its site.
  • To connect: sign in at humblebundle.com, press F12, open Storage (Firefox) or Application (Chrome) → Cookies → www.humblebundle.com, copy the value of _simpleauth_sess, and paste it in Settings → Humble Bundle.
  • Only game assets are listed: products from asset bundles, ones that look like asset packs, and anything already in your library. Games, books and software are skipped.
  • Humble purchases appear in Purchases next to itch.io ones and download the same way, into their own folder. Sync updates both stores.
  • When a product has separate Windows, Mac and Linux builds, only this computer's build is downloaded.

Running Packrat

  • Packrat runs while you use it. Its tray icon reopens it or quits it. Opening it again while it runs just opens it in your browser.
  • Settings → Start when I log in starts it in the background, so scheduled syncs run without opening it.
  • To use it from other computers, or on a NAS with Docker, see the README. Other computers then sign in with a password; this computer doesn't need to.

Connect Claude

Packrat's MCP server lets Claude Code search your library, view previews, read licenses and copy assets into your project. Run this once in a terminal (PowerShell on Windows):

claude mcp add packrat --scope user -- packrat mcp

Restart Claude Code and type /mcp: you should see packrat ✔ connected. Packrat must be running while you use it.

From another computer (when Packrat is open to your network), use the command under Settings → Network access instead; it includes a token.

Using it from Claude

Say "my Packrat library" so Claude uses the Packrat tools. It previews before choosing, checks licenses, and only copies into your project, never changing the library.

Look at the art in ./assets, work out its tile size and style, and find tilesets in my Packrat library that match. Show me previews before copying anything.
Find a treasure chest with an opening animation in my Packrat library and copy it to ./assets/sprites.
Find short UI click and confirm sounds in my Packrat library that go together, and copy them to ./audio/ui.
For every asset you copied from my Packrat library, write a CREDITS.md with each pack, author, link and whether attribution is required.

To make it a habit, add to the project's CLAUDE.md:

Game art, sound, music and fonts come from my Packrat library (packrat MCP tools).
Preview before choosing, match the style of ./assets, and record licenses in CREDITS.md.

Troubleshooting

Something not covered here? Use Report a problem under Settings → About.

Claude doesn't use Packrat, or /mcp shows it failed
Check Packrat is running (this page opens). Run claude mcp remove packrat -s user, then the command from Connect Claude again, and restart Claude Code.
itch.io sync fails or says to reconnect
The API key was revoked or mistyped. Create a new one on itch.io (Settings → API keys) and paste it in Packrat's Settings.
Humble sync says the cookie expired
Humble ends the session when you sign out or after a while. Copy a fresh _simpleauth_sess as described in Humble Bundle and paste it in Settings → Humble Bundle, then press Replace.
.rar or .7z packs show no files
Packrat reads them with 7-Zip, unrar or bsdtar. Windows includes bsdtar, which reads most of them; for the rest, install 7-Zip from 7-zip.org. On Linux install 7zip and bsdtar (Fedora's 7-Zip can't read .rar). Then press Rescan.
No tray icon
Some desktops have no tray (GNOME needs the AppIndicator extension). Quit Packrat from Settings → Quit Packrat.
Forgot the password for other computers
On this computer, set a new one in Settings → Network access, or run packrat set-password (with Docker: docker exec -it packrat packrat set-password).
A purchase says "page removed from itch.io"
The creator removed its page. Its files still download; only the tags and terms are missing.
